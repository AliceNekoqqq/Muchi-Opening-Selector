# 暮迟市 · 开场选择器

角色卡《丧尸少年》的独立开场选择器插件。四张末日剧情插画和一张灾变前校园插画用于开场选择及对应正文；四张环境图用于灾变后的场所介绍。

- `index.js` 只在尚未开始的新聊天中调用酒馆助手 `setChatMessages([{message_id:0,swipe_id:n}])`，切换为角色卡原有开场消息页；不替玩家发送消息，也不修改已经开始的聊天。
- 角色卡的 TavernHelper 脚本加载本插件。`<MuchiOpeningSelector/>` 和八个插图标记由角色卡正则渲染，样式由本仓库的 `style.css` 与 `scene.css` 承载。
- 如果 CDN 或脚本不可用，酒馆自带的首楼翻页箭头仍可选择五个开场。首次开场选择器不属于剧情；五段正式开场及各自 MVU 初始存档保留在后续消息页。
- `Assets/Backgrounds/` 为环境图，`Assets/Scenes/` 为对应剧情瞬间插画。第 1、5、12、31 天的城市变化按开场时间线绘制。
- 四张 `Scenes` 采用同一套偏写实的电影镜头语言：男主沿用状态栏立绘的发型、脸型和神态，保持清瘦、协调的头身比例；女主仅以局部背影入镜。衣着按时间线变化：第一夜校服衬衫、第 5 天灰蓝色薄雨衣、第 12 天橄榄色防割外套、第 31 天磨损的深灰色外套。

版本：`v1.1.0`。第五个开场新增 2023 年秋天正常校园的独立封面。更新角色卡导入标签时，请同步更新正则中的图片和 CSS 地址。
